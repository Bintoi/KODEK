# KODEK - Premium Clothing Brand Website

A modern, responsive e-commerce website for KODEK clothing brand featuring:

- 🛍️ Product showcase with shopping cart
- 📱 Fully responsive design (mobile, tablet, desktop)
- 🎨 Smooth animations powered by Framer Motion
- 🌓 Automatic light/dark mode support
- ♻️ Sustainable fashion focused

## Live Website

🌐 [View Live Site](https://your-username.github.io/kodek-website/)

## Features

- **Product Catalog** - Browse men's, women's, and accessories collections
- **Shopping Cart** - Add items, adjust quantities, view total
- **Persistent Cart** - Cart contents saved in browser
- **Newsletter Signup** - Email subscription form
- **Responsive Design** - Works on all devices
- **Modern Animations** - Scroll-triggered and hover effects

## Technology Stack

- HTML5
- CSS3 (Custom Properties for theming)
- JavaScript (React 18.3.1)
- Framer Motion 11.2.4
- Google Fonts (Cormorant Garamond, Inter)

## Local Development

1. Clone this repository
2. Open `index.html` in your browser
3. Or use a local server like Live Server in VS Code

## Customization

See [GETTING-STARTED.md](GETTING-STARTED.md) for complete customization guide.

### Quick Changes

- **Colors**: Edit CSS variables in `:root` section
- **Products**: Update `products` array in JavaScript
- **Brand Name**: Find and replace "KODEK"
- **Images**: Add to `images/` folder and update paths

## Deployment

This site can be deployed to:
- GitHub Pages (free)
- Netlify (free)
- Any static hosting service
